# evidence/

Bukti uji per workflow (`wf1/` … `wf5/`) dan bukti deploy (`deploy/`). Nama file **bernomor** supaya urut dibaca penilai: `01-canvas.png`, `02-executions.png`, `03-<bukti>.png` (atau `.txt`); untuk `deploy/`: `01-https.png`, `02-compose-ps.png`, `03-curl.txt`.

Isi tiap folder (Minimum dan Nilai penuh): [tabel Evidence](../guide/submission.md#evidence). Jangan menampilkan secret di screenshot (key, token, password, email asli).
